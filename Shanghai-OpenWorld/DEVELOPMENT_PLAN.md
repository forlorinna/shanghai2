# 开发任务清单

## 阶段一 · 可运行核心

- [x] 检查工作环境，安装匹配的 Godot 模板、JDK、API 36 SDK 和构建工具。
- [x] 建立 Godot 工程、3D 基础场景、地面和建筑碰撞、角色骨骼及两种步行视角。
- [x] 建立可上下车的街机车辆，以及多点触屏、键盘鼠标和手柄映射。
- [x] 构建独立签名 ARM64 APK，验证包结构。

## 阶段二 · 上海城市还原

- [x] 下载开放地图，投影至本地米制坐标，建立道路、水域、建筑、公园、桥隧和场景烘焙流水线。
- [x] 生成陆家嘴、外滩、黄浦江和地标模型，标记数据近似。
- [x] 分块加载与卸载、建筑远景合批、实例化绿化和近处物理碰撞。
- [x] 以真实线路为依据制作可行驶的延安东路隧道和外白渡桥。
- [ ] 增加地标逐栋 LOD、测绘标高、复杂立面、连续桥隧出入口和沿街细节。

## 阶段三 · 城市生态

- [x] 基础行人、右侧车流、跟车和 OSM 交通信号灯。
- [x] 昼夜、天气、灯光、水面、过江船、湿路和合成音频。
- [ ] 完整交叉口优先权、车道变换、公交站线与出租调度。
- [ ] 拓展行人过街、坐下、使用手机、闲聊和异常反应。
- [ ] 增加独立云层、建筑反射、额外动态船只及音频内容。

## 阶段四 · 游戏玩法

- [x] 五星追捕基础版、手机、地图导航及传送、九类任务、虚拟货币、车辆和收藏。
- [x] 轮渡、咖啡馆、公寓、拍照、本地存档、备份、沙盒及调试显示。
- [ ] 追加室内、任务叙事与 NPC 乘客、对手竞赛、复杂追捕与独立警员角色。
- [ ] 扩展救护车、消防车、货车和电动车。

## 阶段五 · 画质与性能

- [x] 四个预设、帧率上限、省电、基于帧率和内存的画质降低。
- [x] Compatibility 基线、近远细节切换和网页加载预算。
- [ ] Vulkan Mobile 导出验证、目标真机帧率和长时间压测。
- [ ] 扩展 LOD 自动化、细化遮挡剔除、移动内存回收和流式加载性能验证。
